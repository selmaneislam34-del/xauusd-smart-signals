# XAUUSD Smart Signals — نسخة أولية للهاتف

## المحتويات
- واجهة داكنة متجاوبة مع أوضاع Scalping / Intraday / Swing / Auto.
- محاولة جلب شموع XAU/USD من Twelve Data للفريمات 5m و15m و1h و4h و1d.
- حاسبة مخاطر/لوت تقريبية وسجل صفقات محفوظ محليًا.
- حالة NO TRADE افتراضية؛ هذه النسخة لا تحتوي على استراتيجية تداول موثقة أو نتائج backtest ولا تصدر توصيات دخول آلية.
- يمكن تثبيتها كتطبيق ويب PWA من Chrome بعد نشرها على HTTPS.

## تشغيل مجاني من الهاتف
1. أنشئ مستودع GitHub جديدًا من متصفح الهاتف وارفع كل ملفات هذا المجلد إلى جذر المستودع.
2. افتح Settings ثم Pages في GitHub.
3. اختر Deploy from a branch، الفرع main، والمجلد /(root)، ثم Save.
4. انتظر رابط HTTPS من GitHub Pages.
5. افتح الرابط في Chrome على Android، ثم قائمة ⋮ ثم Add to Home screen أو Install app.
6. افتح التطبيق، اضغط ⚙، أدخل مفتاح Twelve Data الشخصي، احفظ، ثم Refresh data.

قد تتغير أسماء القوائم في الهاتف. لا أستطيع إنشاء مستودع أو نشره داخل حسابك بالنيابة عنك من هنا.

## أمان المفتاح
هذه نسخة شخصية أولية؛ مفتاح Twelve Data يُخزّن في localStorage ويُرسل من المتصفح مباشرة إلى Twelve Data، لذلك يمكن رؤيته ضمن طلبات المتصفح. لا تنشر أو تشارك نسخة فيها مفتاحك. التطبيق العام يحتاج backend proxy آمن. لا تضع المفتاح في ملفات الكود أو GitHub. إذا سبق أن كشفت المفتاح، ألغِه وأنشئ مفتاحًا جديدًا.

## حدود مهمة
- لا نضمن أن الحساب المجاني يتيح XAU/USD وكل الفريمات؛ التطبيق يختبر الوصول فعليًا ويعرض الخطأ إذا لم يكن متاحًا.
- لا يحوّل snapshots من GoldAPI إلى شموع.
- لا يرسل أوامر إلى MT5.
- حاسبة اللوت تقريبية بافتراض 1.00 lot = 100 أونصة. تحقق من مواصفات عقد وسيطك وtick value وvolume step قبل التداول.
- لا توجد استراتيجية مثبتة أو ضمان ربح. لا تتداول اعتمادًا على هذه النسخة وحدها.
- هذه PWA قابلة للتثبيت من المتصفح وليست APK أصليًا. إنشاء APK يتطلب عملية بناء Android إضافية.
